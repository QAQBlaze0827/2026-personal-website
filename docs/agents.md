# 個人網站開發指引

## 專案目標

這是一個個人網站專案，目標是練習手寫前端程式，而不是一次把功能全部完成。

目前第一階段只需要先規劃首頁與主要導覽方向，實作時應保持簡單、可讀、容易修改。

## 第一階段範圍

請先完成一個首頁，首頁最上方需要有 navbar。

navbar 目前只需要兩個主要導覽項目：

- 我看過的動漫
- 我有聽過的歌

這兩個項目可以先做成導覽連結或按鈕，不一定要馬上完成完整頁面內容。

## 視覺方向

整體設計希望偏暗色系。

建議方向：

- 背景使用深色，例如接近黑色或深灰色。
- 文字使用高對比但不要太刺眼的淺色。
- 互動狀態可以使用一個明顯的輔助色，例如藍色、紫色或綠色。
- navbar 要清楚、簡潔，不要加入太多裝飾。
- 首頁可以先保留簡單的標題與介紹文字，避免一次做得太複雜。

## 實作原則

- 優先自己手寫，不要一次自動產生完整網站。
- 每次只完成一小部分，完成後再測試。
- 不要加入目前沒有需求的功能。
- 不要為未來功能先做過多抽象化。
- 如果要新增頁面，先確認路由與資料結構再實作。

## 建議實作順序

1. 建立首頁基本版面。
2. 加上 navbar。
3. 在 navbar 放入「我看過的動漫」與「我有聽過的歌」。
4. 調整暗色系樣式。
5. 確認手機與桌面畫面都能正常顯示。
6. 之後再分別補動漫列表與歌曲列表。

## 暫不處理的內容

第一階段先不要急著完成以下功能：

- 完整動漫資料列表
- 完整歌曲資料列表
- 搜尋、篩選、排序
- 登入或後台管理
- 複雜動畫
- 過度客製化的元件系統
